2. What the five tools can do

ToolCapabilityTypical use
list_elementsSearch by brand, series, keyword or applicable TDS; first 30 by default, paginate with offset+limit, or all=true to return everythingSelection, finding substitutes, screening by water quality
get_elementFull parameters and operating limits of one elementChecking temperature ceiling, pH range, maximum pressure drop
analyze_waterTDS, conductivity, osmotic pressure, LSI/CCPP, salt saturationDeciding whether RO is viable, whether softening or antiscalant is needed
run_designMulti-stage design: pressure, permeate quality, energy, per-stage fluxDesign checking, energy comparison, array optimisation
list_schemesIndustry configuration templatesA starting point when you have no array in mind

What it does not do: equipment pricing, warranty-grade reports from a manufacturer's official software, drawings or civil works. The output is a design draft and a basis for comparison.

3. Six prompts you can copy as-is

① Element selectionPick three Hydranautics brackish-water elements suitable for TDS 2000 mg/L and 100 m³/h permeate per train, and explain the choice and operating limits.
② Water assessmentWhat are the LSI and scaling risk for this water? Ca 40, Mg 20, Na 460, Cl 710, SO₄ 100, HCO₃ 150 mg/L, pH 7.5, 25 °C. Do I need softening or antiscalant?
③ Design calculationESPA2-LD, 30 pressure vessels × 6 elements, 75% recovery, 100 m³/h permeate. Calculate feed pressure, permeate TDS, energy and concentrate saturation, and tell me whether the configuration is sound.
④ Multi-brand comparisonAt the same water quality and duty, run Hydranautics, DuPont and Toray, then compare feed pressure, specific energy, average flux and concentrate LSI in a table and explain the differences.
⑤ Result interpretationWhich figures in this result are out of range? What are the flux, tail-end beta and concentrate LSI, and which parameter should I adjust first?
⑥ Reverse optimisationRight now 100 vessels give 100 m³/h at only 4.5 lmh average flux. Cut the membrane area so flux is around 15 lmh, re-run, and compare capex and energy.

4. Better inputs give better answers

The AI models exactly what you give it, and treats missing items as 0 or defaults. To get a result usable in a proposal, provide all of the following:

CategoryProvideIf missing
Water analysisCa, Mg, Na, K, HCO₃, SO₄, Cl, NO₃, F, SiO₂, Ba, Sr (mg/L)Missing Ba/Sr/SiO₂ understates scaling risk
DutypH, water temperature, permeate flow, recovery, number of trainsDefaults to pH 7.0 / 25 °C, so cold-weather output is overstated
ArrayStages, vessels per stage, elements per vesselThe AI will propose its own array, which may not be what you want
TargetsPermeate TDS or rejection, energy ceiling, capex sensitivityYou get "it calculates" rather than "it is the right choice"
Tip: it is perfectly acceptable to say "use your typical water quality and list your assumptions" — as long as the assumptions appear in the answer so you can check them.

5. Troubleshooting

SymptomCauseFix
The five tools do not appearClient does not support remote HTTP MCP, or the config was not reloadedCheck the client version; restart it fully after editing config; the ?token= form is an alternative
401 / 403Wrong or revoked token, or the Bearer prefix is missingRegenerate in "Personal settings → MCP access" and copy the full token
429 or "daily limit reached"Daily quota exhaustedResets on the next calendar day; contact the administrator for a higher limit
"Token is bound to another IP"A limited token allows one egress IP onlyRegenerate after changing network, or ask for an unlimited token
GET on /mcp returns 405The Streamable HTTP endpoint does not open a GET server-push streamNormal; the client falls back to request/response mode. For SSE transport use /mcp/sse
Results differ from the web app by a few percentDifferent water analysis, temperature, membrane age or fouling factorAlign inputs item by item before suspecting the engine
"Element not found"Name does not match the library stringHave the AI look it up with list_elements first
Platforms that only accept SSE transport (e.g. Alibaba Cloud Bailian "custom MCP service"): these platforms allow sse only. Use the endpoint https://rofilter.cn/mcp/sse, set the transport to sse, and add the header Authorization: Bearer <token>. After the stream opens, the server first sends an endpoint event with the callback URL; all subsequent results come back on the same stream. Clients that support Streamable HTTP can keep using https://rofilter.cn/mcp — both transports expose the same tools and produce identical results.

7. stdio and HTTP config quick reference

stdio (Claude Desktop / Cursor / Windsurf / Qwen Code, etc.)

{
  "mcpServers": {
    "rofilter": {
      "command": "npx",
      "args": ["-y", "rofilter"],
      "env": { "ROFILTER_TOKEN": "rfmcp_your-token" }
    }
  }
}

Streamable HTTP (any HTTP-MCP client)

Endpoint: https://rofilter.cn/mcp
Header:   Authorization: Bearer rfmcp_your-token

SSE-only platforms (Alibaba Cloud Bailian, etc.): https://rofilter.cn/mcp/sse — same tools, identical results.

8. Scope

The API returns a design draft and a basis for comparison; it is not a commercial commitment with guaranteed performance values. For formal design, tendering and warranty calculations, rely on the latest datasheets, official software and contractual terms. Element parameters come from public technical literature and official design software and may change between vendor versions.
