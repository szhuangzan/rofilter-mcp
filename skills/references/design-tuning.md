# 设计结果判读、调参与回归校验

## 一、判读阈值细表

| 指标 | 字段 | 阈值 | 越界处理 |
|---|---|---|---|
| 平均通量 | `averageFlux` | 苦咸水 12–20 lmh；海水 8–12；废水/抗污染 10–17；超低压/纳滤 18–25 | 低→减少 `vessels`；高→增加 `vessels` 或降回收率 |
| 最大通量 | `stages[].maxFlux` | ≤ 1.3 × 平均通量且 < 25 lmh（海水 < 16） | 首段膜过多/单段压差大时易超，减首段膜或加段 |
| 末段 β | `stages[].maxBeta` | ≤ 1.2；> 1.3 必须调整 | 末段容器数偏少 → 调整锥形比或加一段 |
| 段压差 | `stages[].dp` | 单支 ≤ 1.0 bar（按 `get_element` 的最大单支压差）；6 支容器 ≤ 4.1 bar | 增段、增加并联、抗污染膜 |
| 段回收率 | `stages[].recovery` | 单段 ≤ 50%（苦咸水），末段单支平均回收率 10–15% | 单段回收率过高导致末支缺水 |
| 浓水 LSI | `concentrate.lsi` | 无药剂 ≤ 0；有阻垢剂 ≤ 2.0–2.5 | 降回收率/加酸/软化 |
| 浓水 CCPP | `concentrate.ccpp` | 无药剂 ≤ 0；有药剂按厂家曲线 | 同上，加酸最直接 |
| 浓水 SiO2 饱和度 | `concentrate.sio2Sat` | ≤ 100%（无药剂）；≤ 120–150%（专用药剂） | 降回收率优先 |
| 产水 TDS | `permeate.tds` | 由目标水质反推所需脱盐率 | 两级 RO / 高脱盐率膜 / 降低回收率 |
| 渗透压差 | `concentrate.osmoticPressureBar` | 进水压力应显著高于浓水渗透压（留 2–4 bar 净驱动） | 压力不足时系统产不出目标水量 |
| 单位能耗 | `specificEnergy` | 苦咸水 0.3–1.0；海水 2.5–4.5 kWh/m³（带能量回收） | 检查回收率、段间压损、泵效率 |

## 二、调参决策树

```
结果拿到后
├─ 产水流量偏离目标 >1%？ → 检查 permeate_flow_m3h 是总量还是单套、num_trains 是否漏填
├─ 平均通量 < 下限？
│    ├─ 面积反算：面积(m²) = 产水(m³/h)×1000 ÷ 目标通量(lmh)
│    └─ 容器数 = 面积 ÷ (单支面积 m² × 每容器支数)，按 6 取整后重跑
├─ 平均通量 > 上限？ → 增加容器数或降回收率（高回收率会抬高首段通量）
├─ 压力偏高（> 15 bar 苦咸水）？
│    ├─ 温度假设过低？ → 确认实际水温，15℃ 比 25℃ 压力高约 20%
│    ├─ 回收率过高？ → 降至 65–70% 复算
│    └─ 换低压/低能耗膜或增加膜面积
├─ maxBeta > 1.3 或末段通量过低？
│    ├─ 加一段（2 段→3 段）
│    └─ 或末段容器数上调（6:3 → 6:4:2 类锥形）
├─ 浓水 LSI/CCPP 为正？
│    ├─ 降回收率（每降 5 个点，浓缩倍数明显下降）
│    ├─ 加酸：pH 每降 0.1，LSI 约降 0.1
│    ├─ 软化（钠离子交换）— 投资与运行成本最高，但可支撑高回收率
│    └─ 阻垢剂 — 需按药剂厂家允许的 LSI/SiO2 上限
└─ 产水 TDS 超标？ → 两级设计（一级产水作二级进水）/ 高脱盐率膜 / 降低回收率
```

## 三、基准算例（回归校验用，改动工具或版本升级后比对）

输入：


| maxBeta / 段压差 | 1.343 / 0.029 bar |
| 泵功率 / 单位能耗 | 15.02 kW / 0.150 kWh/m³ |

该算例**只用于校验数值一致性，不是合格设计**：600 支元件做 100 m³/h，平均通量 4.5 lmh 远低于下限（投资翻倍），maxBeta 1.34 超限。

修正后的对照（同一水质，仅把 `vessels` 100 → 30，即 180 支）：

| 项目 | 100 支/套（原） | 30 支/套（修正） |
|---|---|---|
| 进水压力 | 3.25 bar | 5.47 bar |
| 产水 TDS | 196.25 mg/L | 48.62 mg/L |
| 平均通量 / 最大通量 | 4.48 / 9.55 lmh | 14.95 / 20.32 lmh |
| maxBeta | 1.343 | 1.265 |
| 单位能耗 | 0.150 kWh/m³ | 0.253 kWh/m³ |

通量从 4.5 提到 14.9 lmh，膜投资降到约 1/3，压力与能耗仍在苦咸水常规区间——这类"降膜面积换投资"的对比正是给用户看的价值点。若 maxBeta 仍偏高，再改两段排布（如 20:10）。

## 四、常见错误清单

| 现象 | 原因 | 处理 |
|---|---|---|
| 计算报错/找不到元件 | `element` 名称与库内字符串不一致（大小写、`-LD`、空格） | 先 `list_elements` 复制准确名称 |
| 产水量正好是目标的 1/N | `num_trains` 填了套数，但 `permeate_flow_m3h` 也按单套填了 | 产水量填系统总量 |
| 压力异常低（< 2 bar） | 回收率过高 + 膜面积过大，产水被"摊薄" | 用通量反算容器数 |
| 浓水 LSI 突然跳高 | 回收率或 pH 改动未同步核对 | 改一项跑一次，保留前后对比 |
| 多段计算末段真空/负压 | 段数过多、锥形比失衡、段间压损过大 | 减少段数或调末段容器数，检查 `interstage_loss_bar` |
| 结果与厂家软件差 5–10% | 水质缺项、温度口径、膜龄/污染系数不同 | 逐项对齐输入后再比较，不要先改结果 |
