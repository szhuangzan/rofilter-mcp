# 水质分析与结垢判读

## 一、输入清单（`analyze_water` / `run_design.water`）

全部按 **mg/L（以离子计）** 输入，不要直接填 "as CaCO3" 的硬度/碱度。

| 分组 | 参数 | 说明 |
|---|---|---|
| 阳离子 | `ca` `mg` `na` `k` | 用户给总硬度时，按 硬度×0.4 = Ca、硬度×0.24 = Mg 折算（as CaCO3 → 离子量，经验折算，需注明） |
| 阳离子 | `nh4` `ba` `sr` | Ba/Sr 常缺项，按 0 会让 BaSO4/SrSO4 风险被低估 |
| 阴离子 | `hco3` `so4` `cl` `f` `no3` `po4` | 碱度 as CaCO3 ÷ 61 × 61 = HCO3 mg/L（当量相等，直接取数值：1 mg/L as CaCO3 ≈ 1.22 mg/L HCO3） |
| 中性 | `sio2` `boron` | SiO2 是结垢硬约束；B 影响海水/灌溉回用 |
| 条件 | `ph` `temperature` | 默认 7.0 / 25 ℃，必须显式声明 |

输入校核：Σ阳离子当量 ≈ Σ阴离子当量（误差 >10% 说明数据有缺项或换算错，需向用户确认）。

## 二、返回指标怎么用

| 指标 | 含义 | 用途 |
|---|---|---|
| TDS / 电导率 | 溶解固体总量 / 电导 | 判断水型、选膜系列、估算渗透压 |
| 渗透压 bar | 范特霍夫式求和 | 与进水压力对比：压力必须明显高于浓水渗透压才有产水 |
| LSI | pH − pHs | 碳酸钙倾向；> 0 结垢，< 0 腐蚀性 |
| Ryznar | 2pHs − pH | 6–7 稳定，> 8 结垢风险低但腐蚀性强 |
| CCPP | 碳酸钙沉淀潜势 mg/L as CaCO3 | 与 LSI 同向，对高盐更敏感；> 0 有沉淀 |
| CaSO4 / BaSO4 / SrSO4 / SiO2 饱和度 % | 相对饱和 | > 100% 即过饱和，必须处理 |
| CO2 / HCO3 平衡 / 碱度 | 碳酸平衡 | 判断加酸量与产水 pH |

## 三、判读与措施（经验值，最终按阻垢剂厂家曲线与现场化验复核）

| 情况 | 结论 | 措施（按代价从低到高） |
|---|---|---|
| 进水 LSI < 0 且 CCPP < 0 | 进水侧不结垢，可直接进 RO | 仍需核算**浓水侧**（浓缩 3–4 倍后 LSI 常转正） |
| 浓水 LSI 0 ~ 2.0 | 需阻垢剂 | 投加有机膦酸/聚合物阻垢剂；或加酸把进水 pH 降到 6.5–7.0（LSI 随 pH 同步下降） |
| 浓水 LSI > 2.0–2.5 | 阻垢剂不足 | 降回收率、加酸、部分软化，三者组合 |
| 浓水 CCPP > 0 且数值大（几十以上） | 碳酸钙风险高 | 优先加酸降 pH，再评估阻垢剂 |
| CaSO4 饱和度 > 100%（无药剂） | 硫酸钙垢 | 降回收率；阻垢剂可放宽到 230% 左右 |
| BaSO4 / SrSO4 饱和度 > 100% | 硫酸钡/锶垢，极难清洗 | 必须降回收率或预处理，阻垢剂可容忍度较高但需厂家确认 |
| SiO2 浓水饱和度 > 100% | 硅垢不可逆 | 降回收率（最有效）、除硅（石灰软化/MgO）、专用硅阻垢剂（可到 120–150%） |
| 进水 SiO2 > 25 mg/L | 高硅水 | 回收率上限按 SiO2 反算：`回收率 ≤ 1 − 进水SiO2 / 允许浓水SiO2` |
| 铁/锰/浊度/SDI 高（未在工具输入项内） | 胶体与污堵风险 | 提醒用户补测 SDI15、浊度、Fe、Mn；SDI15 < 5、浊度 < 1 NTU 是常规前置条件 |
