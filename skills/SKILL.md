# 反渗透系统设计（ROFilter）

## 核心原则

1. **结果必须来自工具**：进水的渗透压、LSI、产水 TDS、压力、能耗，全部调用 `run_design` / `analyze_water` 获取。不要用经验公式或"大概估算"替代计算，也不要手工改写工具返回的数字。
2. **一次完整答复 = 水质判定 + 选型依据 + 设计结果 + 判读结论**。只给一张结果表、不给风险判断，是半成品。
3. **假设要显式声明**：用户没给的参数（pH、温度、离子缺项、污染系数、膜龄）按默认值取，并在答复里写明"按 pH 7.0 / 25℃ / 缺项计 0"。
4. **精度跟随工具**：压力/TDS 保留 2 位小数，能耗 3 位，通量 1 位。不要二次舍入到无法复算。

## 工具与调用链路

| 工具 | 用途 | 何时调用 |
|---|---|---|
| `analyze_water` | TDS、电导率、渗透压、LSI/Ryznar/CCPP、盐类饱和度、碳酸平衡 | 判断能否直接进 RO、要不要软化/加酸/阻垢；设计的第 0 步 |
| `list_elements` | 按品牌/系列/关键词/适用 TDS 检索元件；默认前 30 条，支持 offset+limit 分页与 all=true 全量 | 选型、找替代件、按 TDS 段筛；候选超 30 条时翻页取全 |
| `get_element` | 单件完整参数与运行边界（尺寸、最高温度、pH 范围、最大单支压差） | 选型收敛后核对工况边界，必做 |
| `run_design` | 多段系统设计计算（核心） | 出压力、产水水质、能耗、逐段通量/压差 |
| `list_schemes` | 行业通用配置模板 | 用户没有排布思路时取起点，不能直接当结果 |

标准链路：

```
水质 → analyze_water → list_elements（筛候选）→ get_element（核边界）
     → run_design → 判读 →（不达标）调参重跑 → 输出
```

按问题类型裁剪：

- 只问"这水能不能上 RO" → 只跑 `analyze_water`
- 问"选什么膜" → `list_elements` + `get_element`，给 2–4 个候选与理由；必要时用 `run_design` 各跑一遍比压力与能耗
- 问"多少压力/能耗/产水 TDS" → 直接 `run_design`（选型用候选元件）
- 用户没给水质数据 → 按水类型给一组典型水质并明确标注"示例水质，需以实测为准"（典型值见 `references/water-quality.md`）

## 输入契约

### 水质（`water`）

- 15 项离子全部按 **mg/L（以该离子计）** 输入：`ca` `mg` `na` `k` `nh4` `ba` `sr` `hco3` `so4` `cl` `f` `no3` `po4` `sio2` `boron`
- 未提供的离子按 0 计入 —— 会低估结垢风险（尤其 Ba/Sr/SiO2），结论里要说明
- `ph` 默认 7.0，`temperature` 默认 25 ℃；海水按用户给值，不要默认 25 ℃ 蒙过去
- 用户给的是"总硬度/总碱度（as CaCO3）"时，先换算成 Ca/Mg 与 HCO3 再传入，换算过程写出来

### 元件（`list_elements` / `get_element`）

- `family` 代码：`1`/`5` 海水淡化膜、`2` 苦咸水膜、`4` 抗污染苦咸水膜、`6` 纳滤膜、`7` 超滤膜、`8` 家用/低压 RO 膜、`15` 高容量海水膜
- `brand`：`Hydranautics` / `Toray` / `CSM` / `DuPont` / `Ovay` / `LG` / `Vontron` / `Veolia`（库内 744 件、8 品牌；账号权限不足时可见件数会少，不代表元件不存在）
- **`element` 名称必须与 `list_elements` 返回的字符串完全一致**（含 `-LD` `-4040` `MAX` 等后缀），拼错会导致计算失败
- 选型先用 `tds` 参数筛适用区间，再用 `get_element` 核对最高温度、pH 范围、最大单支压差

### 设计（`design`）

| 字段 | 含义 | 默认 |
|---|---|---|
| `recovery_pct` | 系统回收率 % | 75 |
| `permeate_flow_m3h` | **系统总产水量**（不是单套） | 100 |
| `num_trains` | 套数 | 1 |
| `interstage_loss_bar` | 段间管路压损 bar | 0.207 |
| `fouling_factor` | 污染系数 | 1.0 |
| `membrane_age_years` | 膜已使用年数 | 0 |
| `water_type` | 自来水/地表水/地下水/废水/海水 | 通用 |
| `feed_pressure_bar` | 指定进水压力（定压校核模式，给了就不再自动求压） | 不填 |

`num_trains > 1` 时，`permeate_flow_m3h` 仍是总量，`stages[].vessels` 是**单套**容器数。

### 排列（`stages`）

```json
[{ "element": "ESPA2-LD", "vessels": 100, "elements_per_vessel": 6 }]
```

- 按段顺序给，单段就一个元素
- 经验锥形比：2 段 2:1，3 段 4:2:1（大系统常用 6:3、6:4:2），保证各段通量接近、末段 β 不超限
- 进水流量自检：`feed = permeate ÷ recovery`，与首段 `vessels × elements × 单支产水` 大体匹配

## 结果判读

拿到 `run_design` 返回后，逐项对照下表再下结论（详细阈值与调参见 `references/design-tuning.md`）：

| 指标 | 合理区间 | 越界含义 |
|---|---|---|
| 平均通量 `averageFlux` | 苦咸水 12–20 lmh；海水 8–12；废水/抗污染 10–17；低压/纳滤更高 | 偏低=膜过多、投资浪费；偏高=膜不足、污染快 |
| 最大通量 `maxFlux` | ≤ 1.3 × 平均通量，绝对 < 25 lmh | 首段前端超通量，需减少首段膜或降回收率 |
| 末段 β `maxBeta` | ≤ 1.2（> 1.3 必须调整） | 末段浓水流量相对产水过大，末段缺水、浓差极化与结垢风险 |
| 单段压差 `stages[].dp` | 6 支装容器 ≤ 4–4.5 bar；单支 ≤ 元件最大单支压差（多为 1.0 bar） | 超限易造成元件 telescoping，需增段或增加并联 |
| 浓水 LSI / CCPP | 无阻垢剂：LSI ≤ 0、CCPP ≤ 0；加阻垢剂可放宽（按药剂曲线，LSI 常规到 2.0–2.5） | 正值为碳酸钙结垢倾向，需降回收率/加酸/软化/阻垢剂 |
| 浓水 SiO2 饱和度 | 无药剂 ≤ 1.0，加专用阻垢剂可到 1.2–1.5（随温度） | 硅垢不可逆，优先降回收率 |
| 产水 TDS | 满足用户目标水质的脱盐率要求 | 不达标→两级设计或换高脱盐率/低电导率专用膜 |
| 单位能耗 | 苦咸水 0.3–1.0 kWh/m³；海水 2.5–4.5（带能量回收） | 偏高→回收率过高、压力损失大或泵效率设定不合理 |

**调参优先级（一次只改一个变量，便于归因）**：

1. 通量偏离 → 减/增 `vessels`（按 `膜面积 = 产水 m³/h × 1000 ÷ 目标通量 lmh` 反算，再除以单支面积与每容器支数）
2. 压力过高 → 增加膜面积、提高温度、降低回收率、换低压差/低能耗膜
3. β 超限或末段通量过低 → 增加段数或让末段容器数偏多（调锥形比）
4. 浓水结垢 → 降回收率 → 加酸调 pH → 软化/除硅 → 阻垢剂（按这个顺序说明代价）
5. 产水不达标 → 提高级数（两级 RO），或改选高脱盐率元件

## 输出格式

默认按下列结构答复（用户只要一个数字时，可压缩到 3–5 行）：

1. **设计条件**：水质来源与假设（pH、温度、缺项）、产水量、回收率、套数、元件与排列
2. **关键结果表**：进水压力、产水流量/TDS/pH、浓水流量/TDS、平均通量、泵功率、单位能耗、浓水 LSI/CCPP
3. **判读**：先说结论（能不能用/风险在哪），再逐项给依据
4. **优化建议**：1–2 条，最好附"改前 vs 改后"两列对比（同口径指标）

用户要文件时：方案书用 HTML/docx，逐段结果与对比表用 xlsx；多方案对比统一列同口径指标（压力、能耗、平均通量、末端 β、浓水 LSI）。

## 边界与纪律

- 结果为**设计初稿与方案对比依据**，不构成性能保证；正式报价与担保需按厂家软件、现场水质与合同复核——答复里保留这句
- 不虚构工具没返回的字段；工具报错、名称不存在、配额用尽时如实说明，不猜结果
- 用户给出与计算结果冲突的"内部经验值"时，先复述假设与输入，再解释差异来源（水质、温度、膜龄、污染系数）
- 涉及元件权限：账号无权访问的元件不会返回，不要用相近型号冒充
