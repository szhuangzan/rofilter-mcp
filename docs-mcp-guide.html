一、各 AI 助手接入方式（2026-11 新增）

rofilter 现已发布为 npm 包（rofilter，含零依赖 stdio 服务器 rofilter-mcp），并托管了 tarball 直装包，几乎全部主流 Agent 都能一键接入：

平台接入方式配置要点
豆包 / 扣子 Coze插件 → 创建插件 → MCP → npm：包名 rofilter，命令 rofilter-mcp扣子会自动 npx 拉起；npm 插件包校验失败时改用「本地命令」方式：命令 npx，参数 -y https://rofilter.cn/npm/rofilter/-/rofilter-2.1.2.tgz（自托管 tarball，不走公网 npm）
通义千问（Qwen Code）~/.qwen/settings.json 里加 mcpServers.rofilter = {command:"npx", args:["-y","rofilter"]}需令牌时加 env.ROFILTER_TOKEN；应用编排/百炼平台只能 HTTP：端点 https://rofilter.cn/mcp + Bearer 头
WorkBuddyMCP 服务器设置 → 自定义 MCP：命令 npx，参数 -y rofilter支持远程 MCP 的版本可直接 HTTP 接入
Claude Desktop / Codeclaude_desktop_config.json 或 claude mcp add rofilter -- npx -y rofilter配置 JSON 见下方第八节
Cursor / Windsurf / Zed / Gemini CLI各自的 mcp.json / mcp_config.json / settings.json同为 npx -y rofilter，或 HTTP 直连
DeepSeek Harness插件面板搜索/粘贴 rofilter 安装（配置组合包自动挂载）详见 GitHub 仓库 szhuangzan/rofilter-mcp 的 DEEPSEEK-HARNESS.md
豆包/扣子专属提示：扣子上传 npm 包报「插件包校验失败」时，优先用上面「本地命令 + tarball 直链」方式（不依赖公网 npm 源）；技能（Skill）方式则上传 rofilter-mcp-skill-flat.zip（根目录即 SKILL.md，兼容扣子解压规则）。

二、这 5 个工具能做什么

工具能力典型用途
list_elements按品牌、系列、关键词、适用 TDS 检索元件；默认前 30 条，支持 offset+limit 分页与 all=true 一次取全量选型、找替代、按水质筛候选
get_element单支元件的完整参数与运行边界核对最高温度、pH 范围、最大压差
analyze_waterTDS、电导、渗透压、LSI/CCPP、盐类饱和度判断能否直接进 RO、要不要软化或加阻垢剂
run_design多段系统设计计算：压力、产水水质、能耗、逐段通量方案核算、能耗对比、排列优化
list_schemes行业通用配置模板没有排布思路时取起点

它不做什么：不做设备选型报价、不替代厂家官方软件出具质保计算书、不处理图纸和土建。结果是设计初稿与比选依据。

三、六种典型问法（可直接复制）

① 选型帮我从海德能的产品里选 3 支适合 TDS 2000 mg/L、单套产水 100 m³/h 的苦咸水膜，说明选择理由和运行边界。
② 水质判定这股水的 LSI 和结垢风险怎么样？Ca 40、Mg 20、Na 460、Cl 710、SO₄ 100、HCO₃ 150 mg/L，pH 7.5，25℃。需要软化还是加阻垢剂？
③ 设计核算用 ESPA2-LD，30 支压力容器 × 6 支，回收率 75%，产水 100 m³/h，帮我算进水压力、产水 TDS、能耗和浓水饱和度，并判断配置是否合理。
④ 多品牌对比同样的水质和工况，把海德能、杜邦、东丽各算一遍，用表格对比进水压力、单位能耗、平均通量和浓水 LSI，说明差在哪里。
⑤ 结果判读这个计算结果里有哪些指标越界？通量、末段 β 值和浓水 LSI 分别是多少，超标了应该先调哪个参数？
⑥ 反向优化现在 100 支容器做 100 m³/h，平均通量只有 4.5 lmh，帮我把膜面积压到通量 15 lmh 左右，重新出一版并对比投资与能耗。

四、提问给得越全，结果越准

AI 会按你给的信息建模，缺项按 0 或默认值处理。想让结果能用于方案，最好一次给全：

类别需要提供缺了会怎样
水质Ca、Mg、Na、K、HCO₃、SO₄、Cl、NO₃、F、SiO₂、Ba、Sr（mg/L）缺 Ba/Sr/SiO₂ 会低估结垢风险
工况pH、水温、产水量、回收率、套数默认 pH 7.0 / 25℃，低温工况产水会算多
排列几段、每段几个容器、每容器几支AI 会自己排，可能不是你要的方案
目标产水 TDS 或脱盐率要求、能耗上限、投资敏感度只能给出“算得通”而不是“选得对”
提示：直接说“按你假设的典型水质算，并列出假设”也完全可以，前提是让 AI 把假设写在结果里，方便你核对。

五、常见问题与排查

现象原因处理
客户端里看不到这 5 个工具客户端不支持远程 HTTP MCP，或配置未生效确认客户端版本；改完配置要完全重启；也可用 ?token= 方式
401 / 403令牌错误、已吊销，或头里少了 Bearer 在「个人设置 → MCP 接入」重新生成并复制完整令牌
429 或提示次数达上限当日配额用尽次日自然日重置；需要更多联系管理员
提示令牌已绑定其他 IP限次令牌只允许一个出口 IP换网络/设备请重新生成，或让管理员改为不限次数
GET /mcp returns 405Streamable HTTP 端点的 GET（服务端主动推送）本服务不开放正常现象，客户端会自动改用请求/响应模式；需要 SSE 传输请用 /mcp/sse
结果与网页端差几个百分点水质缺项、温度、膜龄、污染系数不同逐项对齐输入再比较，不要先怀疑引擎
提示“找不到元件”元件名与库内字符串不一致先让 AI 用 list_elements 检索准确名称，再计算
只支持 SSE 传输的平台（阿里云百炼「自定义 MCP 服务」等）：这类平台的传输协议只接受 SSE，请填服务地址 https://rofilter.cn/mcp/sse，协议选 sse，请求头加 Authorization: Bearer <令牌>。建流后服务端先回一条 endpoint 事件告知回传地址，之后的调用结果都走这条流返回。支持 Streamable HTTP 的客户端继续用 https://rofilter.cn/mcp，两条通道的工具与计算结果完全相同。「MCP 服务」面板新增的 SSE 页签可直接复制这份配置。

六、技能包（Agent Skills）

如果你用的客户端支持 Agent Skills（TeleAgent、Claude Code 等），可以直接下载技能包：AI 会按固定的设计流程工作——先判水质、再选型、核边界、跑计算、判读结果，不会跳步，也会把假设写在结论里。

下载技能包（SKILL.md + 3 份参考资料，约 12 KB）

项目说明
包含内容SKILL.md 主流程；references/water-quality.md 水质与结垢判读；references/design-tuning.md 阈值与调参、基准算例；references/access.md 接入与排错
安装方式解压后把 rofilter-design 整个目录放入客户端的 skills 目录，重启客户端
仍需令牌技能只是“怎么用工具”的说明书，不含令牌；请用自己的账号生成令牌填入 MCP 配置
版本rev.3 · 2026-11-02（对应元件库 744 支 / 8 家厂商）；元件库或工具更新后会同步新版本
两种布局标准包（rofilter-design/SKILL.md，Claude Code 等）；扁平包（根目录即 SKILL.md，扣子/豆包技能导入用）
不支持技能包的客户端怎么办：直接把上面第二节的示例问法发给 AI，效果一样——技能包的作用是把流程和阈值固化下来，不是必需项。

七、stdio 与 HTTP 配置速查

stdio（Claude Desktop / Cursor / Windsurf / Qwen Code 等）

{
  "mcpServers": {
    "rofilter": {
      "command": "npx",
      "args": ["-y", "rofilter"],
      "env": { "ROFILTER_TOKEN": "rfmcp_你的令牌" }
    }
  }
}

Streamable HTTP（任意支持 HTTP MCP 的客户端）

端点:  https://rofilter.cn/mcp
请求头: Authorization: Bearer rfmcp_你的令牌

只支持 SSE 的平台（阿里云百炼等）：https://rofilter.cn/mcp/sse，工具与计算结果完全相同。

八、边界说明

接口返回的是设计初稿与方案对比依据，不构成带性能保证值的商务承诺。正式设计、投标与质保计算，请以各膜厂商最新样本、官方软件与合同约定为准。元件参数来源于公开技术资料与官方设计软件，可能随厂商版本调整。
